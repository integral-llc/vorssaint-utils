# .prds

Product requirement documents for this repo, one numbered directory each.

- `prd.md`: the problem, the solution, user stories, implementation and testing decisions, and what is out of scope. Start here.
- `tasks.md`: the implementation checklist, ticked off as work lands.
- `decisions.md`: every change of scope or direction made after the PRD was written, with the reason.
- `_index.md`: all PRDs and their status.

Statuses: `draft` (written, not agreed), `ready` (agreed, not started), `in-progress`, `done`, `abandoned`. A status change is updated in both the PRD header and `_index.md`, and noted in `decisions.md`.

Numbering is sequential; the next number is one past the highest in `_index.md`. The directory is self-contained and can be copied into any repo.
